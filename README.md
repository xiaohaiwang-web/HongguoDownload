# 🎬 红果短剧下载器

一个基于 PySide6 开发的桌面应用程序，用于批量下载红果短剧视频。支持按 ID、URL 或名称搜索，提供友好的图形界面和丰富的自定义选项。
爬虫代码基于wangduoyu001大佬的源码修改而来
https://github.com/wangduoyu001

## ✨ 功能特性

- **三种下载模式**：按剧集 ID、按 URL、按名称搜索
- **批量下载**：支持自定义起始集和结束集
- **灵活配置**：可设置下载延时、Cookie、ffmpeg 路径等
- **测试模式**：仅下载起始集用于验证
- **自测解析**：快速测试解析功能，确保接口可用
- **美观界面**：无边框窗口、动态光标、悬停动画、自定义图标
- **日志显示**：实时输出下载进度和状态

## 📥 下载与安装

1. 前往 [Releases](../../releases) 页面下载最新版本的 `红果短剧下载器.zip`。
2. 解压到任意目录。
3. 双击运行 `红果短剧下载器.exe`。

> **注意**：如果系统提示缺少 DLL 或无法启动，请确认已安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)（通常 Windows 10/11 已自带）。

## 🚀 使用方法

### 基本步骤

1. **选择模式**  
   在“模式”下拉框中选择下载方式：
   - `按 ID`：输入剧集的数字 ID。
   - `按 URL`：粘贴剧集详情页的完整网址。
   - `按名称搜索`：输入剧集名称关键词。

2. **输入目标**  
   在“目标”输入框中填写对应的 ID、URL 或名称。

3. **设置输出目录**  
   点击“浏览...”按钮选择保存视频的文件夹，或直接手动输入路径。

4. **配置下载选项**  
   - **起始集 / 结束集**：设置要下载的集数范围，结束集可填大数字表示全部。
   - **延时(秒)**：每集下载之间的等待时间，避免请求过快。
   - **Cookie**：如需登录后访问，可粘贴浏览器中的 Cookie。
   - **ffmpeg**：可选，用于自定义转码工具路径。

5. **选择测试模式（可选）**  
   勾选“测试模式（仅第起始集）”可以只下载起始集，用于快速验证。

6. **开始下载**  
   点击 **“开始下载”** 按钮。日志区域会实时显示进度。

7. **停止任务**  
   下载过程中可随时点击 **“停止”** 按钮取消任务。

### 自测解析

点击 **“自测解析”** 按钮，程序会自动测试 20 个随机剧集的解析情况，用于检查接口是否正常。

## ❓ 常见问题

**Q：下载失败怎么办？**  
A：请检查目标是否有效、网络是否畅通，必要时尝试使用 Cookie 或更换模式。

**Q：为什么提示 ffmpeg 缺失？**  
A：程序会尝试调用系统 ffmpeg，若未安装可通过“浏览”按钮指定 ffmpeg.exe 路径。

**Q：可以同时下载多个剧集吗？**  
A：目前版本同一时间只能执行一个下载任务，但可以批量下载同一剧集的多集。

**Q：支持哪些平台？**  
A：目前仅支持 Windows 10/11，其他系统暂未测试。
